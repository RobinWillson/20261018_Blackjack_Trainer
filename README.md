# 21點算牌與基本策略 PWA 觸控版訓練器 🃏

專為手機觸控體驗打造的高顏值、全離線 Web App（Progressive Web App）。完美重現所有算牌與基本策略盲測功能，擁有日系淺焙咖啡館風格的溫潤視覺、免鍵盤全按鈕作答、觸控震動反饋、獨立策略速查與弱點回顧分析。

---

## 核心亮點特色

* **免鍵盤、全觸控按鈕作答**：專為 iPhone 單手大拇指觸控最佳化，告別軟鍵盤遮擋螢幕或誤觸問題。
* **日系淺焙燕麥拿鐵風美學**：極簡陶瓷白色卡片、溫潤咖啡拿鐵色調，放鬆無壓力。
* **低調偷玩模式（Stealth Mode）**：右上角可隨時一鍵切換「純英文代碼 `[ 10S ]`」，上班使用不引人注目。
* **100% 純離線原生運行**：內建 Service Worker 離線快取，加入主畫面後即便斷網、飛航模式依然秒開暢玩。
* **獨立基本策略查詢（Strategy Lookup）**：免翻對照表，手牌類型與點數即選即查，秒看面對莊家 2 ~ A 各面決策與戰術口訣。
* **支援 S17s（含投降）與 S17（無投降）**：即時切換規則，策略結果與盲測訓練同步響應。

## 功能架構

### 1. 基本策略訓練（條列式專訓）
* **全方位混題**：硬牌、軟牌、對子、投降隨機出題盲測。
* **硬牌專訓 (Hard)**：9 ~ 17 點關鍵要牌與加倍判斷。
* **軟牌專訓 (Soft)**：A,2 ~ A,9 軟手牌加倍與要牌決策。
* **對子分牌 (Pairs)**：2,2 ~ A,A 最佳分牌攻防策略。
* **投降專訓 (Surrender)**：15、16 點面對大牌精準棄牌止損。

### 2. Hi-Lo 算牌訓練
* **52 張單一副牌衝刺翻牌測速**：全球職業算牌團隊入行標準考核（25~30 秒）。
* **自動節奏定時翻牌訓練**：0.5s ~ 1.8s 自動節奏發牌，考驗流水數記憶。
* **成對視覺抵消練習**：一眼看出兩張手牌淨值（-2 ~ +2），提速必修技巧。
* **真數 (True Count) 心算換算**：TC = RC ÷ 剩餘副數，迅速判斷下注優勢。

### 3. 基本策略即時查詢 (Strategy Lookup)
* 獨立單一頁面，選項一選即更新。
* 包含弱牌區（2~6 易爆區）與強牌區（7~A 進攻區）完整動作色標（H / S / D / P / SU）。
* 附帶戰術記憶口訣。

## GitHub Pages 部署與 iPhone 安裝指南

### 步驟 A：部署到 GitHub Pages（推薦，免開本地伺服器）

1. 將本專案推送到個人的 GitHub 公開倉庫（例如命名為 `blackjack-pwa`）。
2. 在倉庫頁面點選 **Settings** $\rightarrow$ **Pages**。
3. 在 **Build and deployment** 下方的 Source 選擇 **Deploy from a branch**，Branch 選擇 **main** / **/(root)** 並點擊 **Save**。
4. 等待 1~2 分鐘，即可獲得專屬 HTTPS 網址：`https://<你的GitHub帳號>.github.io/blackjack-pwa/`。

### 步驟 B：在 iPhone Safari 加入主畫面（原生 App 體驗）

1. 用 iPhone 的 Safari 瀏覽器打開該 GitHub Pages 網址。
2. 點擊 Safari 底部工具列中央的「**分享**」圖示（帶箭頭的方框）。
3. 往下滑動找到並點選「**加入主畫面**」（Add to Home Screen）。
4. 手機桌面即會產生獨立的 App 圖示，點開即全螢幕啟動，且斷網離線亦可 100% 正常運作！
